## Open MLflow UI

Run from the repository root:

```bash
cd /Users/joseph/qlib
conda activate quant
mlflow ui --backend-store-uri ./mlruns --port 5000
```

Then open:

```text
http://127.0.0.1:5000
```

Select the experiment:

```text
CPO_Strategy_Research
```

For the current run:

```text

```

## Experiments

| Experiment name | Short name for `--exp-name` | Description |
|---|---|---|
| `CPO_Strategy_Research` | *(omit `--exp-name`)* | Single-horizon CPO baseline |
| `CPO_5Day_Strategy_Research` | `CPO_5Day` | 5-day CPO variant |

## Key Artifacts

The key files are under:

```text
mlruns/331389798673625822/58b1013be7c447b4b3a23ae9c4aaaa6f/artifacts/
```

Important files:

```text
pred.pkl
portfolio_analysis/port_analysis_1day.pkl
portfolio_analysis/indicator_analysis_1day.pkl
```

What they mean:

```text
pred.pkl
```

Model prediction scores. The index is usually `(datetime, instrument)`, and the main column is `score`.

```text
port_analysis_1day.pkl
```

Backtest risk and return summary, including excess return with and without transaction cost.

```text
indicator_analysis_1day.pkl
```

Trading indicator summary, such as `ffr`, `pa`, and `pos`.

## View Artifacts With Script

Use:

```bash
cd /Users/joseph/qlib
conda activate quant
python examples/view_exp_artifacts.py
```

Show fewer rows:

```bash
python examples/view_exp_artifacts.py --rows 3
```

Show a plain action plan:

```bash
python examples/view_exp_artifacts.py --action-plan
```

This prints:

```text
current holdings
SELL candidates
BUY candidates
HOLD candidates
```

The action plan reads the workflow strategy setting from `examples/workflow_by_cpo.py`:

```text
TopkDropoutStrategy(topk=5, n_drop=2)
```

So it normally changes two stocks at a time instead of replacing the whole portfolio.

Export the three pandas artifacts to CSV:

```bash
python examples/view_exp_artifacts.py --exp-name 5D_Mid_Term --export-csv
```

The CSV files are written to `data_train_results/<run-dir>/`. The directory name is derived from `--exp-name`:

| `--exp-name` form | Export directory |
|---|---|
| `5D_Mid_Term` | `data_train_results/5D_Mid_Term/` |
| `1D_Short_Term` | `data_train_results/1D_Short_Term/` |
| *(omitted)* | `data_train_results/CPO_Strategy_Research/` |
| `mlruns/<exp_id>/<run_id>` | `data_train_results/<run_id>/` |

Generated files:

```text
data_train_results/5D_Mid_Term/pred.csv
data_train_results/5D_Mid_Term/port_analysis.csv
data_train_results/5D_Mid_Term/indicator_analysis.csv
```

Export CSV files plus the plain action plan:

```bash
python examples/view_exp_artifacts.py --exp-name 5D_Mid_Term --action-plan --export-csv
```

This also creates:

```text
data_train_results/5D_Mid_Term/action_plan.csv
data_train_results/5D_Mid_Term/candidate_top10.csv
```

`action_plan.csv` includes:

```text
action
instrument
score
weight
interpretation
feature_reason
reason
```

`feature_reason` explains concrete indicators from `workflow_by_cpo.py`, such as MA trend, volume expansion, price-volume correlation, and volume-adjusted return.

`candidate_top10.csv` lists the top 10 current candidates by model score, with the same feature-level explanation.

The feature explanation is a readable approximation based on the latest cross-section: model score direction, feature importance, and each stock's feature percentile. It is not exact SHAP attribution.

### Selecting which run to view

`--exp-name` accepts three forms:

**1. Experiment name (recommended) — always picks the latest run automatically:**

```bash
# Latest run of Dual_Horizon_5D_Mid_Term
python examples/view_exp_artifacts.py --exp-name 5D_Mid_Term

# Latest run of Dual_Horizon_1D_Short_Term
python examples/view_exp_artifacts.py --exp-name 1D_Short_Term

# Latest run of CPO_Strategy_Research (same as omitting --exp-name)
python examples/view_exp_artifacts.py --exp-name CPO_Strategy_Research
```

The name is matched as a substring against each experiment's MLflow name, so short fragments like `5D_Mid_Term` or `1D_Short` both work.

**2. Explicit path — view a specific historical run:**

```bash
python examples/view_exp_artifacts.py --exp-name mlruns/<experiment_id>/<run_id>
```

**3. Omit entirely — uses the latest CPO run (default, unchanged):**

```bash
python examples/view_exp_artifacts.py
```

To override the export directory:

```bash
python examples/view_exp_artifacts.py --exp-name 5D_Mid_Term --export-csv --export-dir my_custom_dir
```

```bash

```

## Other Useful Artifacts

These are also useful when analyzing the backtest:

```text
portfolio_analysis/report_normal_1day.pkl
portfolio_analysis/positions_normal_1day.pkl
portfolio_analysis/indicators_normal_1day.pkl
```

Use `report_normal_1day.pkl` to inspect daily account value, daily return, cash, and benchmark return.

Use `positions_normal_1day.pkl` to inspect daily holdings.

Use `indicators_normal_1day.pkl` to inspect daily trading activity.
