# 这份报告里各项指标的含义

这份报告来自双周期策略实验，重点看的是“信号质量”和“组合回测表现”。

## 1. 先看整体结构

报告分成两部分：

- summary：记录这次运行的基本信息，比如任务名、持仓数、是否做了回测。
- metrics：记录模型和策略的核心评估指标。
- details：记录本次预测的前几条结果和最新推荐股票。

其中最关键的是 metrics 里的几个指标。

## 2. 主要指标含义

### 2.1 IC / ICIR

- IC：信息系数，衡量“预测分数”和“未来收益”之间的相关性。
- 取值越接近 1，说明模型预测越靠谱。
- 取值越接近 0，说明信号和真实收益关系很弱。
- 负值说明模型预测方向和未来收益方向相反。

- ICIR：IC 的均值除以标准差，表示信号稳定性。
- 如果 ICIR 很大，说明信号不但相关，而且稳定。
- 如果 ICIR 很小甚至为负，说明信号噪声大，效果不稳。

### 2.2 Rank IC / Rank ICIR

- Rank IC 是用“排序”关系来衡量预测的好坏，而不是直接看数值大小。
- 它更关注“谁排前、谁排后”是否和未来收益一致。
- 这比普通 IC 更适合做选股排序任务。

- Rank ICIR 是 Rank IC 的稳定性指标。

### 2.3 excess_return_without_cost

这是“去掉手续费前”的超额收益。

- mean：平均超额收益，越大越好。
- std：波动率，越小越稳定。
- annualized_return：年化收益率，反映长期收益水平。
- information_ratio：信息比率，衡量每单位风险带来的收益，越高越好。
- max_drawdown：最大回撤，表示最严重的亏损幅度，绝对值越小越好。

这个部分反映的是：如果不考虑交易成本，策略到底能不能赚钱。

### 2.4 excess_return_with_cost

这是“考虑手续费和交易成本后”的超额收益。

- 它比 without_cost 更贴近真实交易效果。
- 如果 without_cost 很好，但 with_cost 很差，说明策略在实际交易中并不划算。
- 这通常是最重要的现实指标。

### 2.5 ffr / pa / pos

- ffr：free-float rate / 资金使用效率/换手相关指标，常用于衡量策略是否有太多无效交易。
- pa：持仓占比相关指标，通常表示策略持仓规模或使用情况。
- pos：持仓位置指标，反映当前持仓状态。

这些指标通常不是最核心的重点，但能辅助判断策略是否过度交易、是否太激进。

## 3. 这里这份报告里的数值意味着什么

以这份报告为例：

- IC = 0.027，ICIR = 0.187：说明信号相关性是弱的，但不是完全没用。
- Rank IC 和 Rank ICIR 为负，说明排序能力并不强。
- without_cost 的年化收益和信息比率都比较不错，说明模型在理论上有一定选股能力。
- 但 with_cost 的收益和信息比率明显变差，说明真实交易中成本让收益被削弱了。
- 这说明：模型“有信号”，但“交易成本把优势吃掉了”。

## 4. 如何判断策略好不好

可以这样理解：

- 如果 IC / ICIR 高，说明模型预测能力强。
- 如果 without_cost 好、with_cost 也好，说明策略实盘潜力高。
- 如果 without_cost 好、with_cost 很差，说明策略要么太频繁交易，要么成本太高。
- 如果两者都差，说明这套策略本身不够有效。

## 5. 你可以把它理解成一句话

这份报告在说：

- 模型的“选股方向”有一点点参考价值；
- 但它在真实交易中没有把这个优势稳定地转成高收益；
- 所以它还不能算是一个非常强的可实盘策略。
